03Layout

base.html.twig ya incluye esta estructura. La cabecera que ves arriba es el componente real.

<header class="site-header">
  <a class="site-brand" href="/">Red_Social</a>
  <nav class="site-nav">
    <a href="/tweets" aria-current="page">Timeline</a>
    <a href="/tweet/add">Publicar</a>
    <span class="site-nav-user">@ana</span>
  </nav>
</header>
<main class="site-main"> … </main>
ClaseComportamiento
.site-headerFija arriba, translúcida y con una línea de neón animada debajo
.site-brandLogotipo; el rombo gira en hover
.site-nav aIndicador cian en hover. La página activa se marca con aria-current="page"
.site-nav-userEtiqueta mono en magenta para el usuario con sesión
.site-mainMáx. 1280px, rejilla asimétrica 7/3: el contenido va a la izquierda. Una sola columna por debajo de 768px

Para ocupar la columna derecha (como el índice de esta página):

<aside style="grid-column: 2; grid-row: 1 / span 100; position: sticky; top: 96px;">…</aside>

05Formularios

Los inputs, textarea, select y label no necesitan clases: los form_row() de Symfony salen estilados directamente.

Entre 3 y 20 caracteres
  • Este email no es válido
  • Error: un <ul><li> dentro del div (es lo que genera Symfony) pone el campo con borde rojo y el mensaje debajo.
  • Foco: anillo cian de 2px separado 2px del campo. No hay labels flotantes.

Con mensajes flash de Symfony (los tipos son success, danger, warning e info):

{% for type, messages in app.flashes %}
  {% for message in messages %}
    <div class="alert alert-{{ type }}">{{ message }}</div>
  {% endfor %}
{% endfor %}
Los controladores todavía no llaman a addFlash(), así que habría que añadirlo para usar este patrón.

11Tooltip

Solo funciona con CSS, a través de data-tooltip, y ocupa el ::after del elemento. En elementos que ya lo usan (por ejemplo, los enlaces de .site-nav), ponlo en un elemento que lo envuelva.

16Reglas del sistema

Sí

  • Patrones geométricos (rombos, hexágonos, rayos) con CSS o SVG inline
  • Brillos de neón en hover y foco
  • Composiciones asimétricas y zig-zag
  • Entradas en cascada
  • Cian solo para enlaces, foco y la acción principal

No

  • Emojis en la interfaz: usa iconos SVG (Lucide, Heroicons) o formas CSS
  • Fondos blancos puros
  • Rejillas de 3 columnas iguales
  • 100vh: usa min-height: 100dvh
  • Spinners circulares ni labels flotantes
  • Lorem ipsum, ni clichés como "Eleva" o "Sin fisuras"
